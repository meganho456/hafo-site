# PMS Compatibility

## The four supported systems

| System        | Market           | Integration method            | Status           |
|---------------|------------------|-------------------------------|------------------|
| Open Dental   | USA              | MySQL read + REST write-back  | Live production  |
| Plato Medical | Singapore / APAC | PlatoConnect REST API         | Planned          |
| Dentrix       | USA              | Dentrix API / HL7 FHIR        | Roadmap Q3 2026  |
| Eaglesoft     | USA              | Native API / ODBC bridge      | Roadmap Q4 2026  |

## Plato Medical context
platomedical.com — most widely adopted web-based clinic software in Singapore.
4,000+ providers across SG / AU / APAC.
Integrates via **PlatoConnect** developer API — no direct DB access needed.
Name Plato Medical explicitly when addressing Singapore clinic audiences.
